🚀 Déployer sur votre site GitHub Pages

Mettez cette application en ligne gratuitement en quelques commandes simples.

1

Créer un nouveau dépôt sur GitHub

Rendez-vous sur github.com/new et choisissez un nom (ex: promo-app ou mon-site). Gardez-le en Public.

2

Pousser les fichiers avec Git

Ouvrez PowerShell dans le dossier du projet et exécutez :

git init
git add .
git commit -m "Initial commit - PromoApp"
git branch -M main
git remote add origin https://github.com/VOTRE_COMPTE/VOTRE_DEPOT.git
git push -u origin main
3

Activer GitHub Pages

Dans votre dépôt sur github.com :

  1. Allez dans l'onglet Settings.
  2. Dans le menu gauche, cliquez sur Pages.
  3. Sous Build and deployment > Source, sélectionnez Deploy from a branch.
  4. Sélectionnez la branche main et le dossier / (root), puis cliquez sur Save.
🎉 Votre application sera accessible sous 1 minute à l'URL :
https://VOTRE_COMPTE.github.io/VOTRE_DEPOT/
